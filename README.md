# dankin.github.io

素问语料阅读器。3848 条论断、3651 条「反对」，可检索、可筛选、附一份提问清单。
静态站点，无依赖，GitHub Pages 从 `main` 根目录发布，线上地址 `dankin.win`。

## 功能

- **检索** — 搜索问题、论断、「反对」、标题。多词用空格分开，按交集匹配；命中的词在列表、详情面板、正文里都会高亮。
- **筛选与排序** — 按领域、年份筛选，可只看有「反对」的或有张力的；支持按日期、长度排序。卡片上的领域、日期、「有张力」都是按钮，点一下就筛。
- **详情面板** — 点开一条看正文、principles 和来源链接，可复制链接或引用。
- **提问清单** — 34 条 move，勾选状态存在浏览器本地。
- **深色模式** — 右上角 ◐ 切换，默认跟随系统。
- **链接即状态** — 当前这一屏的搜索、筛选、打开的论断全在 URL 里，复制出去别人看到的就是同一屏，刷新也回到原处。

## 使用

| 快捷键 | |
|---|---|
| `/` | 聚焦搜索 |
| `j` / `k` | 上下条。列表里移动焦点，走到底自动翻页；面板打开时直接翻到上一条/下一条 |
| `Esc` | 关闭面板 |

URL 参数：

| | |
|---|---|
| `?q=` | 搜索词 |
| `?domain=` `?year=` | 领域、年份 |
| `?sort=` | `date-desc`（默认） `date-asc` `len-desc` `len-asc` |
| `?rejects=1` `?tension=1` | 只看有「反对」的 / 有张力的 |
| `?view=checklist` | 提问清单页 |
| `#<8 位短 id>` | 打开某条论断 |
