# 06 音频与美术

## 1. 配乐

**原则**：一段主旋律，多层变奏。音乐本身就是进度条，也最适合开放世界逐步扩展。

| 项目 | 方案 |
|---|---|
| 主旋律 | 原创一段简单的圣诞风旋律，避免版权风险；公有领域曲目（如 Jingle Bells）只在彩蛋里引用一小段 |
| 清晨 | 钢片琴、单音 |
| 午后 | 加吉他和手风琴 |
| 傍晚 | 加弦乐 |
| 平安夜 | 加合唱，下雪的静谧感 |
| 人物主题短句 | 小米=人声哼唱，阿福=木管，老周=手风琴，小蓝=钢琴，阿冬=小号和鼓点 |
| 叠加规则 | 一条线完成，对应主题短句永久加入背景音乐 |
| 中西融合 | 可以加一点民乐元素（笛、二胡、琵琶）做点缀，与"中西合璧"一致 |

**技术**：Web Audio，多轨分层，由"已完成故事"和"全镇暖度"驱动淡入淡出。`【待确认 Q13】`

## 2. 音效

- 每种可附身物件有独特声音：风铃、邮筒投信、气球飘走、自行车铃、贩卖机掉货、公交车报站（可带一点沪语/普通话/英语三语报站的小玩笑）。
- 搞笑音效库：失败时的"啵""咚""哇"，统一风格。
- 帽子：叮、抖、"钻进去"的音效。

## 3. 配音

| 项目 | 方案 |
|---|---|
| 日常角色 | "哼声语言"，每个角色一种音色，配气泡文字（类似动森） |
| 真人 | 两处：小米唱出的第一句；终章最后一句 "May all the beauty in the world be blessed." |
| 旁白 | 可选，一位低沉温暖的声音，开场和终章使用 |
| 帽子 | 无台词 |
| 文本语言 | 首版简体中文，英文作为后续本地化 `【待确认 Q14】` |

选择"哼声语言"的原因：开放世界内容会持续增加，全程配音不可持续。

## 4. 美术规范（像素 + 暖色）

| 项目 | 方案 |
|---|---|
| 视角 | 等距 2.5D |
| 瓦片尺寸 | 建议 64x32 的等距瓦片 `【待确认 Q15】` |

| 手机适配 | 竖屏优先还是横屏优先 `【待确认 Q16】` |

## 6. 音频 API

> 由 music 维护。实现：`game/src/core/audio.ts`（门面，`import { audio } from '../core/audio'`）+ `game/src/audio/*`（rig 混音、music 配乐、sfx 音效、ambience 氛围、theory 乐理表、selftest 自检）。全部 WebAudio 合成，无外部素材。

**混音总线**：`music / sfx / ambience` 三条 gain → 轻混响（代码生成脉冲响应的 ConvolverNode）→ 压缩器 → 软限幅 → master。`duck()` 临时压低音乐与氛围。页面隐藏（`visibilitychange`/`pagehide`）自动 `suspend`，回到前台或下一次手势 `resume`；全局只有一个 AudioContext，HMR 时自动 `dispose`。

### 调用清单
| API | 说明 |
| --- | --- |
| `audio.unlock()` | 必须在**首次用户手势**里调用（标题页点击）。创建上下文，之后配乐自动开始。可重复调用 |
| `audio.setMuted(m)` / `audio.muted` | 静音开关（旧 API 不变） |
| `audio.setVolume(kind, v)` / `getVolume(kind)` | `kind`: `'master' \| 'music' \| 'sfx' \| 'ambience'`，`v` 0~1.5，默认 1。给 hud 音量滑杆用 |
| `audio.setRegion(id \| null)` | 区域氛围，id = `plaza/bakery/slope/alley/bridge/dock`，自动交叉淡入淡出（约 1 s）；切区域时调用 |
| `audio.setWeather({rain,snow,wind})` | 天气层，各 0~1.5。`setRain(v)` 仍可用（等价只设雨） |
| `audio.setWarmth(0..100)` | 暖度：影响音乐明亮度（低通）与“叮”的音高阶梯 |
| `audio.storyMotif(id)` | 故事主题动机（一小节内对齐到下一小节），返回开始等待秒数；id 可为 `xiaomi/afu/laozhou/xiaolan/adong/finale`，也接受 `xiaomi_story`、`abao`、`courier` 等别名 |
| `audio.storyDone(id)` | 故事完成：庆祝乐句 + 该故事动机并入配乐循环 + 加一层；`finale` 触发平安夜终章（含《平安夜》Gruber 1818，公有领域，引用 8 小节） |
| `audio.sting('start'\|'hint'\|'fail'\|'win')` | 一次性乐句 |
| `audio.cue(name, arg?)` | **乐段 cue**（见下表），返回是否识别。unlock 之前调用会被记住，unlock 后补放。`audio.cueState` / `audio.cueLen` 给调试/对齐字幕用。dev-core 的 bus `audio:cue` → `audio.cue(cue,arg)` |
| `audio.duck(ms, depth=0.35, ambDepth=0.55)` | 对白/演出时压低音乐（ms 后自动恢复）；blast/prelude 音效会自动 duck |
| `audio.setLayer(n)` | 旧 API：基础层数 0~5（实际层数 = max(setLayer, 已完成故事数)）。可不再调用 |
| `audio.setTempo(mul)` / `setTranspose(semi)` | 变速 / 变调（循环仍然无缝） |
| `audio.resetProgress()` | 新游戏时清空已完成故事 |
| `audio.sfx(id, p?, {pan?,vol?})` | 音效，返回是否真的发声（同类限流时 false）。`p`：`step`=地面材质字符串，`blip`=频率，`warm`=暖度 |
| `audio.tone / noise / playPhrase / theme(voice)` | 旧 API 不变 |
| `await audio.selfTest({quick?})` | 离线自检，见下 |

### 乐段 cue：`audio.cue(name, arg?)`

### 音效 id
`chime`(风铃) `whoosh`(气球飞走) `pop`(气球破) `prelude`/`blast`(喇叭前奏/炸响) `sparkle` `lamp`(灯亮) `tree`(圣诞树亮) `boing`(雪人摆姿势) `letter`(投信) `meow` `bike`(自行车铃) `bus`(公交喇叭) `busstop`(报站) `stove`(炉灶火焰) `door`(门铃) `bubble`(气泡弹出) `tick`(清单打勾) `warm`(暖度“叮”) `possess`/`release`(附身/离开) `clank` `fail`(失败“啵/咚”) `shake`(帽子抖) `vending`(贩卖机) `laugh` `gull` `ship`(汽笛) `click`(UI) `cheer` `bus_ramp` `snow_blow` `oven_stoke` `vend_blind` `dog_snore` `cat_purr` `whistle` `cheer_crowd` `confetti` `bell_sled` `paper` `fish_swing` `egg`/`egg_ding|accordion|cat|bikes|choir` `blip`(`p`=Hz) `step`(`p`=`grass|snow|wood|stone|sand|carpet`)。
`moves.json` 里的 sfx 名可直接用，别名表在 `SFX_ALIAS`：`chime_ring→chime`、`balloon_release→whoosh`、`balloon_pop→pop`、`speaker_prelude→prelude`、`speaker_blast→blast`、`lamp_glow→lamp`、`tree_twinkle→tree`、`snowman_pose→boing`、`mailbox_drop→letter`、`cat_meow→meow`、`bike_bell→bike`、`bus_horn→bus`、`stove_fire→stove`、`doorbell→door`、`bubble_pop→bubble`、`checklist→tick`；未知 id 退化为 `blip`，不会报错。同类有最小间隔，每 250 ms 最多 8 个低优先级音效；`blast/possess/release` 为高优先级，不被限流。

### 配乐结构
- 主旋律原创，C 大调 / G 大调共用的五声“安全音” D E G A；16 小节、84 BPM、8 分音符网格，数据表在 `audio/theory.ts`（`PROGRESSION`、`MELODY_BARS`、`CHORDS`、`MOTIFS`、`MOTIF_SLOT`）。`validateTheory()` 检查旋律/和声/动机无冲突。
- 层随“已完成故事数”加入：0 钢片琴 → 1 木吉他 → 2 低音 → 3 弦乐垫 → 4 轻打击 + 哼唱 → 5 铃铛；终章加合唱并汇聚。
- 每条故事动机：xiaomi 童声哼唱、afu 渐快小提琴拨弦、laozhou 暖低音木管、xiaolan 钢琴水彩、adong 鼓点+号角冲线、finale 合唱。动机在循环中的固定小节出现（`MOTIF_SLOT`，自动挑选与旋律/低音不冲突的小节）。

### 接入建议（给 dev-core）
1. 标题页点击 → `audio.unlock()`；开局 `audio.resetProgress()`。
2. 切区域 → `audio.setRegion(regionId)`；相位变化 → `audio.setWeather({rain: v.rain, snow: v.snow, wind: v.wind})`（原 `setRain` 可删）。
3. 暖度变化 → `audio.setWarmth(warmth)`；故事开始 `audio.storyMotif(id)`，完成 `audio.storyDone(id)`；对白/演出 `audio.duck(2500)`（音频内部只为动机/sting/终章/收音机自动 duck）；剧情 cue → `audio.cue(name)`。
4. 脚步 `audio.sfx('step', '地面材质')`；hud 音量/静音 → `setVolume` / `setMuted`。
5. 配乐在 unlock 后约 1.8 s 自动开始，`audio.theme(true)` 与 `setLayer(1)` 的延时调用可保留也可删。

### 自检（给 qa）
浏览器控制台（dev server）：`await audio.selfTest({quick:true})`，或 `await (await import('/src/audio/selftest.ts')).runSelfTest()`；用 OfflineAudioContext 渲染，不发声。检查：峰值 < 0.95、无 NaN、直流偏移、静音检测、限流（连发 40 次只出声 ≤ 8）、区域/天气非静音、最坏叠加（满层音乐+氛围+暴风雨+全部音效）峰值、循环缝合无爆点、乐理表。输出 `console.table`（每层 peak / RMS dB）与 `Report{ok, rows, failures, warnings}`。最近一次完整结果：全部通过，满混音乐峰值 0.60 / RMS −21 dB，最坏叠加峰值 0.78。
