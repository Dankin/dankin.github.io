# 05 幽默系统

## 1. 目标与边界

- 目标：治愈为主，多幽默；中式、西式、讽刺都有。
- 比例：中式 : 西式 = 6 : 4（已确认）。
- 讽刺对准行为、风气和系统，不对准弱者。
- 笑点来自"错位"，不来自恶意。结局是大家一起笑，没有人真正受伤。

### 内容边界（已确认）

- 不嘲笑疾病、残障、贫穷、年龄、外貌、地域。
- 不对宗教或真实品牌做冒犯性调侃。
- 宗教元素（如圣诞传统）只当文化背景。
- 小米的颤抖、老周的失落、阿冬的轮椅，永远不当笑点。

## 2. 两种风格

| 风格 | 手法 | 示例 |
|---|---|---|
| 中式（zh） | 谐音梗、市井烟火、沪语口音词汇、熟人社会的热心与多管闲事、吐槽体、对联、春晚式夸张 | 阿姨在群里转发"今晚平安夜，转发 10 个人才平安"；外卖小哥对着圣诞树说"您的餐已送达"；店铺对联"上联：来都来了 下联：买点什么 横批：不买也行" |
| 西式（western） | 干冷讽刺、肢体喜剧、荒诞因果、机关陷阱、对传统的反讽 | 过度装饰的邻居让整条弄堂跳闸；街头辩论"圣诞老人是不是真的"；火鸡逃跑 |

沪语口音只作点缀，避免对方言使用刻板印象。`【待确认 Q12】`

## 3. 讽刺对象（可以调侃）

- 打卡式过节、朋友圈营销、KPI 式热情。
- 商业化的圣诞、过度促销、无限满减。
- 小区群里的吵架和转发。
- 导航软件的过度提示。
- 办事排队和各种"请出示……"。

## 4. 在框架里的位置

| 机制 | 内容 |
|---|---|
| 口头禅库 | 每个 NPC 一份，日常随机冒出 |
| 吐槽库 | 烦躁度第二档使用，按风格和档位分类 |
| Gag 表 | "物件 × NPC"或"现象 × 现象"的专属搞笑反应，没配则走通用反应 |
| 事故反应表 | 玩家组合"不太对"时选一条搞笑失败，不惩罚 |
| 隐藏笑点 | 对物件做"不合理"的操作触发彩蛋，如对圣诞树连点十次 |
| 旁白字幕 | 关键场景一句短旁白，如"这位邮递员已经绕路 17 天，他的导航都快哭了" |

## 5. 烦躁度（打扰反馈）

同一 NPC 被同类现象反复打扰：

1. 皱眉（表情变化）。
2. 吐槽（头顶冒一句话，来自吐槽库）。
3. 走开（离开去别处，冷却后回来）。

不扣分，不影响进度，只增加笑点和"别太吵"的真实感。

## 6. 示例库（占位，之后扩充）

**小米**：吐槽"我在练声！不是在开演唱会！"
**阿福**：口头禅"导航又在骗我。"
**老周**：口头禅"我这炉子，比我年纪还大。"
**围观阿姨**：口头禅"你看看人家的孩子。"
**咖啡馆老板**：吐槽"圣诞特供，三十八块一杯的雪。"
**物业**：广播"请业主勿将雪人堆放在消防通道"。

## 7. 质量要求

- 每条吐槽不超过 20 个字，适合气泡。
- 每个 NPC 至少 6 条口头禅，6 条吐槽，保证短时间内不重复。
- 同一个笑点最多触发 3 次，之后换内容。
- 写作审查：每条笑点回答"笑的是谁，笑什么"，笑的对象不是弱者。
