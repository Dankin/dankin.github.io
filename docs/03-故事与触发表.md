# 03 故事与触发表

说明：触发链是"推荐解法"，实际由 04 文档的"现象→感知→反应→决心"规则决定。玩家用别的物件组合达成同样效果也应被接受，乱试则产生搞笑反馈。每条线约 3 到 5 分钟，另有可选小分支。

内容层标签：`main` 主线，`side` 支线，`ambient` 环境彩蛋。

## 1. 小米的独唱（勇气 · main · 中央广场 · 上午）

- **心结**：想在平安夜社区合唱团独唱，一开口就发抖。周围吵闹时更紧张。
- **提示色**：蓝。
- **推荐解法**：
  1. 附身风铃，轻轻响一声。小米抬头，进入"想听"的状态（决心 +1）。
  2. 附身气球摊的气球，让它飘走，周围的人和孩子去追，小米身边安静下来（决心 +1）。
  3. 附身广场喇叭，放一小段前奏（决心 +1）。小米忍不住跟着哼，哼出声。
- **决心满**：小米自己唱出第一句（真人录音，全局两处真人之一）。
- **搞笑失败**：顺序错了，气球飞去砸路灯，人群乱成一团；喇叭太大声，小米吓得躲到长椅后面。
- **隐藏项**：用风铃加喇叭让鸽子合唱。
- **连锁**：歌声传向邮局弄堂，给阿福的故事加一份氛围。
- **完成奖励**：帽子补上白边。小米带着"歌声"去终章。

## 2. 绕路的邮递员阿福（勇气 · main · 邮局弄堂 · 上午）

- **心结**：怕狗，每天绕三条弄堂，已迟到一个星期。
- **提示色**：蓝。
- **推荐解法**：
  1. 附身邮筒，吐出一封信，飘到狗院子的门口（引起阿福的注意）。
  2. 附身流浪猫，把信叼进院子里，引起狗的反应（狗只是想闻信）。
  3. 阿福担心信丢了，自己走进院子，发现大狗只是摇尾巴。
- **决心满**：阿福自己第一次走进狗的院子。
- **搞笑点**：猫和狗互相打招呼，阿福脑内上演"猫狗大战"；狗对信的兴趣大于对人的兴趣；阿福的导航 App 一直在提示"您已偏离路线"。
- **隐藏项**：把一根骨头放在邮筒上，狗会自己来取信。
- **完成奖励**：绒球长回来。阿福带着"一封信"去终章。

## 3. 老周的面包店（振作 · main · 面包街 · 午后）

- **心结**：老店歇业，不再烤面包，觉得"没人会买了"。
- **提示色**：灰。
- **推荐解法**：
  1. 附身路灯，照亮橱窗里的旧围裙和面粉袋，勾起回忆（决心 +1）。
  2. 附身自动贩卖机，掉出一块饼干，被路过的小孩捡到，小孩说"好香"（决心 +1，小成功体验）。
  3. 附身炉灶，点起火。老周伸手摸一下面团（决心 +1）。
- **决心满**：老周自己重新开始和面、烤面包。
- **搞笑点**：第一炉烤焦了，大家还是抢着吃；"咸味俄式面包"和"圣诞蛋糕"两派路人争论哪种才是"正宗"。
- **连锁**：香味顺风飘向旧车站，影响小蓝。
- **完成奖励**：帽子出现金线。老周带着"一篮面包"去终章。

## 4. 画不出画的小蓝（振作 · main · 旧车站 · 午后）

- **心结**：对着白纸三天没落笔，怀疑自己。
- **提示色**：灰。
- **推荐解法**：
  1. 香味到来（来自老周的故事），小蓝抬头（决心 +1）。若老周线未完成，可用候车厅的小摊代替，但效果弱。
  2. 附身自行车，让它歪倒，滑到雪人旁边（决心 +1）。
  3. 附身雪人，玩家摆出各种滑稽的姿势，小蓝忍不住想画它（决心 +1）。
- **决心满**：小蓝画下第一笔。
- **隐藏项**：雪人的姿势有多个，不同姿势对应不同的画，收集进图鉴。
- **搞笑点**：雪人被晒化变成一摊水，小蓝说"这才是抽象派"。
- **完成奖励**：绒球圆满带光。小蓝带着"一幅画"去终章。

## 5. 雪橇赛上的阿冬（自强 · main · 滨江坡道 · 傍晚）

> 场景设定（人造雪坡）见 `【待确认 Q2】`；表现方式需复核 `【待确认 Q21】`。

- **心结**：想参加社区圣诞雪橇赛，起点台阶太高，同伴已经出发。他不求别人推，也不想被围观。
- **提示色**：橙。
- **推荐解法**：只清障碍，不替他做。
  1. 附身公交车，在起点旁停靠，放下无障碍斜板。
  2. 附身路灯，照亮一条通往起点的路线。
  3. 附身气球，吸走挡路的围观人群的注意力。
- **玩家全程不能操作阿冬**。他自己到达起点、自己出发。
- **写作要求**：镜头给他的动作和表情，不给同情。他的台词是"让一让，我赶时间"这一类，带一点傲气。
- **决心满**：阿冬自己滑出去。可选分支：陪跑支线，让路人在路边打气，不替他赢。
- **音乐**：全局情绪最高的一段，小号和鼓点。
- **完成奖励**：帽子长出小铃铛。阿冬带着"雪橇铃"去终章。

## 6. 终章：平安夜（开朗总线 · main · 中央广场）

- **前置**：5 条线全部完成，进入夜晚，下雪。
- **过程**：
  1. 5 位主角各自带着自己的东西来到广场。
  2. 玩家用 3 到 5 个物件把灯串依次接通：路灯、邮筒、风铃、炉灶、公交车各接一段。
  3. 每接通一段，对应人物拿出自己的东西，暖度互相放大。
  4. 全镇点亮，下雪，帽子长出身体。
- **结局**：帽子变成圣诞老人，先摸自己的肚子，然后"哇"。画面拉远，镇子全亮。最后一行字：

> May all the beauty in the world be blessed.

- **通关后**：进入沙盒，时间固定在温暖的夜晚。

## 7. 开场教学（约 3 分钟）

- 帽子在雪堆里醒来，被狗叼走又放下（搞笑）。
- 教学内容：点击移动、点击附身、选择招式、观察 NPC 气泡。
- 教学物件：风铃，顺手触发小米的"想听"状态。

## 8. 彩蛋与沙盒内容（main 之外）

| 彩蛋 | 触发 | 层 |
|---|---|---|
| 雪人变同伴 | 给雪人戴上小帽子，它会跟着你散步 | ambient |
| 影子戏 | 路灯打在墙上特定位置，出现动物影子 | ambient |
| 圣诞老人来信 | 邮筒随机掉出小朋友的信，每封一个微型故事 | side |
| 贩卖机盲盒 | 掉出袜子、一只鸭子、一张彩票，送给不同 NPC 有不同反应 | side |
| 猫的派对 | 流浪猫带你去一个秘密地点 | ambient |
| 合唱 | 让三位以上 NPC 同时在广场，音乐叠起来 | side |
| 隐藏曲 | 按顺序敲风铃、邮筒、路灯 | ambient |
| 圣诞树十连击 | 对圣诞树连续点十次 | ambient |
| 弄堂群聊 | 阿姨群"转发 10 个人才平安"，用邮筒和手机亭触发 | ambient |
| 线灯跳闸 | 过度装饰的邻居，灯串让整条弄堂跳闸，玩家可以修复或加剧 | side |

沙盒内保留每位完成者的日常变化：老周每天烤新面包，小米偶尔在广场唱歌，阿福路过狗院子会打招呼。
