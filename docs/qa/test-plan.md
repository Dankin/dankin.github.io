# 《圣诞帽帽》测试计划（QA）

维护：qa · 版本 v1（M1）· 配套：`test-matrix.md`（product，功能用例矩阵）、`bugs.md`（缺陷）、`report-*.md`（回归报告）、`game/tests/README.md`（框架用法）

## 1. 目标与准出标准

交付门槛（M4 前必须全部满足）：

| 项 | 标准 |
|---|---|
| 缺陷 | **P0/P1 清零**；P2 ≤ 5 且均有说明；P3 记录不阻塞 |
| 主线 | 6 条故事 + 终章，**纯真实点击**脚本全部通关；整条主线 ≈30 分钟（加速）脚本无报错 |
| 稳定性 | 回归套件连续 3 次全绿；console/页面错误 = 0；`[data]` 校验警告 = 0 |
| UI | 任何时刻气泡 / 招式面板 / toast / 暖意清单 / HUD 互不遮挡（自动检测，容差 80px²） |
| 世界 | NPC 不进建筑/水里/出界，物件不悬空，帽子不出界 |
| 性能 | 桌面（SwiftShader 软渲染）空闲 ≥ 30fps、主线战斗场面 ≥ 20fps；30 分钟压力后纹理数/JS 堆无持续增长（见 §5.4） |
| 触屏 | 手机横屏 844×390：可点目标 ≥ 44×44 CSS px；拖动/长按/点击全部可用，无页面缩放/滚动 |
| 存档 | 刷新/关页后进度（故事步骤、清单、暖度、帽子外观）完整恢复；坏存档不崩溃 |
| 文案 | 全部文本来自 zh.json；无 key 外露（形如 `say.xxx`）、无 `undefined`、无超框 |
| 音频 | `src/audio/selftest.ts` 自检全通过；静音按钮/失焦静音生效 |

## 2. 范围

**范围内**：H5 网页版游戏（桌面 + 手机浏览器）：标题/开始、帽子移动与附身、招式面板、NPC 感知-反应-决心、6 个故事 + 终章、暖意清单、暖度/帽子成长、昼夜与天气、区域切换、存档（localStorage + 导出/导入）、触屏、音频、文案、性能、兼容。

**范围外**：后端/多人/支付；非中文语言；真机 iOS 实测（用 WebKit 模拟 + 用户自测，见 §3）。

## 4. 测试类型与用例

用例编号 `T-<类>-<序号>`；自动化脚本放 `game/tests/specs/`，括号内为脚本文件。**功能用例矩阵由 product 在 `test-matrix.md` 提供，本文补充边界/负面/非功能用例。**

### 4.1 冒烟（每次提交后 1 分钟内）
- T-SMK-1 启动无报错、标题屏出现、点击开始进入世界、`[data]` 无警告、帧率与资源基线（`01-smoke`）。

### 4.2 功能：真实点击通关（`02~07-story-*`、`08-finale`）
每条故事一份**真实点击**脚本（点物件→点招式按钮，不得调用 runSequence/completeStep/useMove 捷径），断言：
- 每步完成后：故事 `done` 增加、对应 NPC 状态/气泡正确、暖度上涨、清单项打勾；
- 故事完成后：完成奖励（帽子外观）、连锁事件（小米歌声→阿福氛围；面包香→小蓝）、带去终章的物品；
- 终章：5 人到齐、5 段灯串依次接通、帽子变圣诞老人、末句 “May all the beauty in the world be blessed.” 出现、进入沙盒夜晚；
- 全程调用 `__qa.overlaps()` 检测遮挡；`invariants()` 检测穿帮。

### 4.3 主线压力（`09-stress-mainline`，≈30min 游戏时间）
一条脚本串起开场教学→6 故事→终章，用 `setSpeed(k)` 加速（NPC 移动/tween/计时同步加速）：
- 每 30 秒真实时间采样：帧时间 p95、纹理数、显示对象数、tween 数、JS 堆；
- 断言：无异常；资源增长斜率 < 阈值（泄漏判据）；通关用时在设计范围。

### 4.4 边界与负面（`10-negative`、`11-negative-story`，用例并入 `test-matrix.md` 的 N 段）

| 编号 | 场景 | 预期 |
|---|---|---|
| N-01 | 开场前 20 次乱点（地面/物件/NPC/UI/屏幕边缘）随机猴子测试，固定种子可复现 | 不崩溃、无 console 错误、不卡死（locked 不会永久为 true） |
| N-02 | 招式冷却中连点同一招式按钮 20 次 | 只触发一次；按钮置灰/提示冷却；刺激不叠加；无重复气泡 |
| N-03 | 连点骚扰同一 NPC（点人 30 次） | 提示“帽子不能附身人”节流（≈4s 一次）；不堆叠 toast；NPC 不被卡死/不出界 |
| N-04 | 点不可附身的人（所有 NPC） | 帽子抖动 + 提示，不进入附身；面板不弹 |
| N-05 | 故事进行中被打断：小米“calm”保持期间又点别的物件/切走区域 | 状态可恢复：quiet 计时重置，不卡在半完成；提示正确回退 |
| N-06 | 顺序错误：先放喇叭再放风铃/气球 | 触发搞笑失败反馈（躲起来/吓到），事后仍可继续完成，不永久锁死 |
| N-07 | 邮递员/路人路过正在进行的故事 | 路人不触发故事步骤；quiet 判定把路人计入“人群”但不死锁 |
| N-08 | 存档中途读档：故事第 N 步时 reload | 步骤、清单、暖度、帽子外观、NPC 状态恢复；提示计时合理；不重复触发已完成演出 |
| N-09 | 坏存档（非 JSON、版本过旧/未来、缺字段、超长）导入/读取 | 不崩溃；提示或回退新档；可恢复 |
| N-10 | 跨故事联动乱序：面包线先于/晚于小蓝线；歌声先于/晚于阿福 | 都能通关；联动加成存在或有替代路径；不出现“前置未完成但步骤已满足” |
| N-11 | 快速切换区域：连点相隔很远的地面 10 次 / 连续在 6 个区域边界来回 | 帽子移动平滑、镜头不抖/不穿帮；区域名 toast 不堆叠；NPC/物件按区域正确加载/卸载 |
| N-12 | 窗口缩放（960×540 ↔ 1920×1080 ↔ 竖屏）与失焦/回前台 | 画布 FIT 无拉伸；点击坐标仍准；失焦时游戏暂停或静音、回来不“快进”；HUD 不溢出 |
| N-13 | 演出中点击（sequence 锁定期） | 点击被忽略，不排队、不丢失；演出结束后可操作 |
| N-14 | 双击/长按/拖动在面板按钮、清单、静音按钮上 | 不误触地面移动；无穿透 |
| N-15 | 同一帧点击物件与相邻 NPC/重叠物件 | 命中优先级一致（物件优先，按深度） |
| N-16 | 暖度到 0/满值边界；重复完成同一清单项 | 不超界、不重复加分、不重复弹 toast |
| N-17 | 时间/昼夜：快进到各阶段边界；跨“夜晚”时正在演出 | 昼夜切换不打断演出；NPC 夜间行为合法；终章条件（夜晚+下雪）判定正确 |
| N-18 | 连续通关两遍（重置存档后再玩）/ 通关后继续沙盒 30 分钟 | 无残留状态；沙盒日常变化生效；无泄漏 |
| N-19 | 隐藏项/彩蛋：风铃+喇叭引鸽子、圣诞树连点十次、雪人戴帽、骨头放邮筒 | 触发一次、不重复；不破坏主线 |
| N-20 | 打开 `?debug=1` 与正式模式对比 | 正式模式无 `__qa`、无调试按钮/F 键捷径 |

### 4.5 UI / 视觉 / 体验（`12-visual-overlap`、`13-visual-shots`）
- **遮挡自动检测**（用户明确反馈过）：在每个故事关键帧、多 NPC 同屏、连点气泡、toast 连发、面板打开 + 气泡 + 清单展开三者同屏时，调用 `__qa.overlaps()`，检查气泡↔气泡、气泡↔面板/HUD/清单、toast↔面板/清单、越出屏幕；`clippedTexts()` 检查文本裁切。任何命中 = P1。
- **关键帧截图**：每区域（6 个）× 昼夜 4 阶段、每故事每步、终章关键帧 → 对比（人工+自检）手绘风格一致性：描边/调色/抖动笔触是否统一、像素比例（PX=2）一致、无缺图/黑块/透明洞、无纹理拉伸。
- **穿帮**：NPC 在建筑/水里/障碍上；物件悬空（脚下为水/空）；物件与装饰重叠遮挡可点区域；地图边界外露；镜头越界；深度排序错误（人站到屋顶上）。
- **触屏目标尺寸**：`__qa.touchTargets()` 全部 ≥ 44×44 CSS px（当前静音 ≈23×24、调试 ≈21×20 需放大）。
- **文案**：遍历 zh.json 的所有 key 在游戏内是否被使用/是否缺失；气泡文字超框/换行；错别字抽检；语气一致。

### 4.6 性能（`14-perf`，E1/E2/E6）
- 帧时间 p50/p95/p99/max 与 >50ms 帧数：空闲、多 NPC 同屏、特效密集（雪/粒子/终章灯串）、面板开关、区域切换瞬间；
- 资源：纹理数/估算显存、显示对象、tween、粒子、JS 堆；启动时间（`load`→可点击）与首帧时间；
- 低性能档：CPU 4× 下仍可玩（≥15fps）、不出现 >500ms 长帧链；`lowend` 降级（如果实现）生效。

### 4.7 兼容（E1~E8）
- 桌面 Chrome/Safari、手机横屏：WebGL 可用性、音频解锁（首次点击后）、localStorage 可用/被禁用（隐私模式）时的降级提示、`devicePixelRatio` 1/2/3 清晰度；
- 浏览器事件：右键菜单、双击缩放、长按选中文本、滚动/橡皮筋、返回键、全屏/旋转。

### 4.8 存档（`15-save`）
读/写时机、自动存档节流、`导出/导入`往返一致、清档、多标签页同时打开、存档版本迁移、容量；对应 N-08、N-09。

### 4.9 触屏（`16-touch`，E3/E4）
tap 移动/附身/点招式；**拖动**（镜头/或拖物件，视 dev-core 最终实现）；**长按**（预览提示/招式说明）；多指/捏合不缩放页面；按钮 ≥44px；手势与点击不互相误判（拖动结束不触发点击）；横竖屏切换不丢状态；`touch-action:none`、无 300ms 延迟；招式面板在 844×390 下不遮挡主角与目标。

### 4.10 可玩性（人工 + 数据）
用 `playStory` 记录“每步用时/尝试次数/提示层级”；乱试玩家（随机/组合错误）可恢复；提示分级（hintDelays）在卡住后确实出现且指向正确；主线时长 ≈ 30 分钟（非加速估算 = 脚本用时 × 人类系数）。

### 4.11 音频自检（`17-audio`）
调用 music 的 `src/audio/selftest.ts`（接入方式见 README，music 提供入口后写入）：音色/采样加载、各 SFX/BGM key 存在且可播放、静音/音量、失焦静音、首次手势解锁、同时发声上限、无爆音（峰值检测）。结果写入报告“音频自检”一节。

## 5. 自动化设计要点

### 5.1 分层
`lib/session`（浏览器/输入/采样）→ `lib/driver`（通关/猴子）→ `specs/*`（断言）→ `run-all`（汇总）→ `lib/report`（报告）。

### 5.2 “真实点击”判据
通关脚本只可用：`page.mouse`/CDP 触摸 + `window.__qa` 的**只读**接口（坐标换算、状态读取）。禁用：`runSequence / completeStep / useMove / setWarmth / teleport*`。夹具/压测允许使用 `advance/setSpeed/setPhase`（只改时间流速）。

### 5.3 防抖与稳定
- HMR 冻结（避免他人保存源码导致整页刷新）；固定猴子种子；等待用“条件 + 超时 + 现场状态打印”，不用盲 sleep；失败自动截图 + 状态 dump。
- 软渲染下 tween/寻路耗时较长，所有等待上限按 ×3 设定。

### 5.4 泄漏判据
压力脚本每 30s 采样 `textures / displayObjects / tweens / jsHeapMB`。去掉前 2 个采样点后做线性回归：纹理数斜率必须 ≈0；显示对象/tween 斜率 < 1/分钟；JS 堆 30 分钟增长 < 30MB 且回收后不单调上升。

## 6. 缺陷管理
见 `bugs.md`。等级：P0 阻塞（崩溃/无法通关/存档损坏）、P1 严重（主线步骤失败、UI 遮挡、穿帮明显、触屏不可用）、P2 一般、P3 体验。发现即 `send_message` 给负责人：dev-core（场景/UI/存档/触屏/输入）、dev-story（故事/NPC/刺激/特效）、art-world（场景/物件美术）、art-char（角色/帽子美术）、music（音频）、product（数据/文案/设计）。修复后 qa 复验并关闭。已知缺陷在脚本断言上标 `{bug:'BUG-xxx'}`，报告显示 🟡。

## 7. 里程碑与节奏
- **M1**：框架 + testApi + 冒烟 + 小米真实通关脚本 + 本计划 + 缺陷表。
- **M2**（随交付持续）：每条新故事交付即补通关脚本；每日跑回归；视觉对比；N 系列负面用例。
- **M3（集成）**：全线真实点击通关、30 分钟压力、触屏全套、性能报告、`npm run build` 验证（qa+lead）、Safari 手测清单、音频自检。
- **M4**：P0/P1 清零复验；最终报告。

## 8. 需要 dev 配合
1. dev-core：`main.ts` 在 `?debug=1` 时 `import('./debug/testApi')` 并 `installTestApi(game)`；`hud.qaRects()` / `bubbles.qaRects()`；招式按钮 `setData('qa','move:<id>')`；存档 key 约定；触屏手势事件命名。
2. dev-story：`Npc` 暴露 `state/x/y/def`；故事系统暴露 `stories` 映射（多故事）与 `current()`；刺激列表 `stim.active`。
3. music：`selftest.ts` 对外入口 `runAudioSelfTest(): Promise<{name,ok,detail}[]>`。
4. product：`test-matrix.md`、每步“预期气泡/状态”表、完成奖励与联动的可验收描述。
