# 02 地图与区域

## 1. 地点气质：上海式中西合璧

镇名暂定"冬青里"，`【待确认 Q1】`。整体是一个像上海老城厢与法租界交界的街区：

- 石库门弄堂、梧桐树、老洋房、咖啡馆、沿街小铺。
- 煎饼、生煎、老式面包房，和圣诞花环、霓虹灯串并排。
- 弄堂口的晾衣竿挂着圣诞袜。
- 老式电车或公交车、旧火车站（或轮渡码头）。
- 远处能看见江边的高楼灯光，作为"大城市背景"。

建筑和招牌要让玩家一眼读出"中西混搭"，是地图的主要视觉辨识度。

首版只做一个街区，保持高密度，每走约 10 秒能看到一个可点击的东西。

## 3. 地标引路

用地标和颜色引导，不用任务箭头。

| 内核 | 头顶标记 | 颜色 |
|---|---|---|
| 勇气（胆小） | 小颤抖的气泡 | 蓝 |
| 振作（颓废） | 灰云 | 灰 |
| 自强 | 小火苗 | 橙 |
| 开朗（总线） | 星光 | 金 |

远处的烟囱冒烟、钟楼、坡顶的灯，都是玩家想去看看的目标。

## 4. 时间

游戏内一天，约 30 分钟真实时间，时钟自动前进，玩家可在阶段内停留。

| 时段 | 天色 | 内容 |
|---|---|---|
| 清晨 | 冷蓝 | 教学，小米前半段 |
| 上午 | 淡金 | 勇气线 2 条 |
| 午后 | 暖黄 | 振作线 2 条 |
| 傍晚 | 橙红 | 自强线 |
| 夜晚（平安夜） | 深蓝加灯光 | 终章 |

做完一个时段的主要故事才进入下一个时段，防止信息过载。天色和灯光同时受"全镇暖度"影响。

## 5. 天气

首版只做两种：晴冷和下雪。`【待确认 Q8】`

- 平安夜下雪：上海难得的一场雪，作为终章的情绪高点。
- 雪天：声音传得更远，部分 NPC 日程变化（面包店"开门"状态）。
- 后续可加雨、风，复用同一套天气系统。

## 6. 扩展区域（后续内容包，首版不做）

| 区域 | 设想 |
|---|---|
| 老人公寓 | 钟表匠停了所有钟，沿用"振作"模板 |
| 海边灯塔 / 外滩 | 孤独的守灯人，"让更多人开心"的支线 |
| 医院儿童区 | 小病房里的孩子和折纸 |
| 夜市 / 小吃街 | 市井幽默主场 |
| 弄堂深处 | 邻里群聊、晾衣竿、阳台上的圣诞灯串 |

每个区域保持 2 到 3 个主角，加几个环境彩蛋，新增 2 到 3 种可附身物件。
