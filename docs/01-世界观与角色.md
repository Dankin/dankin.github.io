# 01 世界观与角色

## 1. 帽子

**身份**：一顶没有名字、没有记忆的旧圣诞帽。它隐约记得一个声音说"去暖一暖别人"。终章揭晓：它是上一任圣诞老人留下的最后一点暖意。`【待确认 Q5】`

**能力**：
- 在地图上飘行，无碰撞，带轻微漂浮感。
- 点击任意可附身物件，播放一小段"钻进去"的瞬移动画，一次只附身一个。
- 通过物件的"招式"在世界里制造现象（声音、光、香味、移动目标等）。
- 不能附身人，不能直接控制人。

**限制与性格**：没有台词，只有抖一下、叮一声、害羞地缩起来这类小动作。被夸会抖，被狗叼走会装死。

### 成长线（外观随进度变化）

| 阶段 | 帽子外观 | 小幽默 |
|---|---|---|
| 开局 | 褪色、塌的灰红旧毛线帽，绒球掉了一半 | 路人把它当垃圾，被狗叼走过一次 |
| 第 1 条线完成 | 红色变鲜亮，补上一圈白边 | 白边是从雪人围巾上蹭来的 |
| 第 2 条线完成 | 绒球长回来，歪歪的，像只小鸡 | 玩家会给它起外号 |
| 第 3 条线完成 | 一条金线，来自面粉烘出的暖光 | |
| 第 4 条线完成 | 绒球圆满，带一点光 | 被夸会害羞抖一下 |
| 第 5 条线完成 | 光泽，长出小铃铛 | 铃铛一响就暴露位置 |
| 终章 | 长出身体，变成圣诞老人 | 先摸自己的肚子，然后"哇" |

进度驱动：见 04 文档的"暖度"。外观阶段由已完成的主线数量决定，彩蛋可以额外解锁挂饰和围巾。

### 装备与内核的对应（视觉隐喻）

靴子对应勇气，围巾对应振作，腰带对应自强，白胡子和笑声对应让更多人开心，红袍是全部集齐。该对应是否保留，见 `【待确认 Q6】`。

## 2. 人物总览

人物按内核分四类，每类使用同一套反应模板（见 04 文档）。名字和细节是占位设定，已按上海气质调整。

| 内核 | 人物 | 年龄/身份 | 心结 | 所在 |
|---|---|---|---|---|
| 勇气 | 小米 | 约 9 岁小学生 | 想在平安夜社区合唱团独唱，一开口就发抖 | 广场 |
| 勇气 | 阿福 | 中年邮递员 | 怕狗，每天绕三条弄堂，已迟到一周 | 邮局弄堂 |
| 振作 | 老周 | 60 多岁面包师 | 老店歇业，不再烤面包 | 面包街 |
| 振作 | 小蓝 | 20 多岁画家 | 对着白纸三天没落笔 | 老洋房阁楼 / 旧车站 |
| 自强 | 阿冬 | 约 15 岁轮椅少年 | 想参加社区的圣诞雪橇赛，起点台阶太高 | 滨江坡道 / 社区雪坡 |
| 总线 | 全镇居民 | | | 终章汇聚 |

### 人物写作要求

- **小米**：颤抖不是笑点。笑点来自周围的人和物件制造的错位。
- **阿福**：怕狗不被嘲笑。笑点在狗的反应。
- **老周**：失落是真实的，笑点来自面包事故，不拿他的处境开玩笑。
- **小蓝**：笑点来自雪人的姿势和画的变化。
- **阿冬**：目标是比赛，不是被帮助。玩家只清障碍，全程不能操作他。轮椅不当同情道具，也不当笑点。

### 配角与背景人物（沙盒期补充，先占位）

- 对圣诞装饰过度热衷的邻居（灯串让整条弄堂跳闸）。
- 在小区群里转发各种"平安夜转发 10 个人才平安"的阿姨。
- 一边送外卖一边带孩子的单亲妈妈（后续内容包）。
- 小店老板，每天照常开门（后续内容包）。
- 流浪猫（可附身物件，也是 NPC 的"朋友"）。
- 小霜精灵：淘气的冬寒，怕被忽略，最后被暖化。`【待确认 Q7】`

## 3. 阻力设定

没有真正的坏人。阻力来自冬寒、孤单、误会和凑巧。小霜精灵可以做成"搞砸现场的小东西"，也可以不做。

## 4. 结局

平安夜，前面被帮助过的人带着各自的东西来到广场（小米的歌声、阿福的信、老周的面包、小蓝的画、阿冬的雪橇铃）。玩家把广场灯串接通，全镇点亮，帽子长出身体变成圣诞老人，最后一句：

> May all the beauty in the world be blessed.

通关后进入沙盒，时间固定在温暖的夜晚，居民保留新习惯（老周每天烤面包，小米偶尔在广场唱歌）。
