## 一句话

一顶朴素的旧圣诞帽，在平安夜这一天里附身街角的物件（风铃、路灯、邮筒、雪人、流浪猫……），悄悄制造"恰到好处的巧合"，帮胆小的人鼓起勇气、帮颓废的人重振精神、陪困境中自强的人走过难关、让更多人开心。每帮成一件事，帽子就变好看一点，最后长出身体，变成圣诞老人。

## 四个内核（不可动摇的导向）

1. 帮助胆小的人鼓起勇气
2. 帮助颓废的人重振精神
3. 帮助困难中自强的人度过难关
4. 让更多人开心

## 一条硬规则

帽子不能替人做决定，只能创造契机，最后一步必须由本人迈出。帽子不能附身人。

## 已定的关键决定

| 项目 | 决定 |
|---|---|
| 视觉 | 像素风 + 暖色调，等距 2.5D |
| 参考 | 《死神来了》（地图密度、连锁）、《捣蛋鹅》、《旷野之息》（系统化互动）、Cozy Grove、星露谷（日程） |
| 平台 | H5，网页和手机同一套，只用点击和拖动 |
| 玩法 | 完全解谜，难度低，失败有搞笑反馈，不惩罚 |
| 时间 | 游戏内一天（清晨到平安夜），主线约 30 分钟 |
| 世界 | 开放世界框架，先做好框架，内容后加；通关后进入沙盒 |
| 首批内容 | 6 个故事（5 条人物线 + 终章） |
| 地点气质 | 上海式的中西合璧街区 |
| 幽默 | 中式 : 西式 = 6 : 4，治愈为主，多幽默 |
| 幽默边界 | 不嘲笑疾病、残障、贫穷、年龄、外貌、地域；不对宗教或真实品牌做冒犯性调侃；讽刺对准行为和风气，不对准弱者 |
| 配音 | 角色用"哼声语言"加气泡文字；关键时刻用真人 |
| 终章最后一句 | May all the beauty in the world be blessed. |
